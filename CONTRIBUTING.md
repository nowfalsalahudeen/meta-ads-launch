# Contributing

Issues and pull requests are welcome, especially:

- **Meta UI changes.** Screens and button names move; if a step in `references/campaign-walkthrough.md` no longer matches, say what you see now.
- **New traps** you hit on a real first run (add a row to the lessons table in `SKILL.md`).
- **Layouts** for the image script (more shapes, more card styles) that keep the rule "show the real product".
- **Verified compliance notes** with a link to the official source. Unverified claims belong in the "to verify" list, not as rules.

Please keep the skill product-neutral: no brand names, accounts, pixel ids, emails or customer data in examples. Use fictional products and placeholders.

Before sending a change that touches `scripts/make_creatives.py`, run it on `examples/ads.json` and look at the output.
